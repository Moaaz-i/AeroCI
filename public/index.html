What this page is

This is a static read of .github/workflows: file names, job counts, step counts and triggers, parsed on every request. It is not a run.

Nothing here has been executed, so nothing here is verified. To check a workflow, run aeroci check. To execute it, run aeroci run — and read what it prints about steps it could not simulate.

The API is this project's own, on this machine: GET /api/status, /api/workflows, /api/workflow?file=…, /api/history, /api/health.
